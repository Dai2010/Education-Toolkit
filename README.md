# Education Toolkit

一个面向学校、教学场景的工具包，使用 Electron 构建，GPL-3.0 授权。

## ✨ 核心功能

### 📱 桌面时钟
- 保留 Elegant Clock 的核心时钟体验（居中时钟、倒计时、自定义设置）
- 启动1秒后自动进入紧凑模式（可拖动的圆角卡片）
- 实时显示当前课程和课间状态
- **完整周课表视图**：传统网格布局，一眼看清整周安排
- 当前课程高亮显示（上课中深紫色高亮，课间时前后课程同时高亮）
- 今天列头高亮，快速定位当天课程

### 🎲 随机抽人
- **单人模式**：随机抽取一位同学
- **分组模式**：可设置每组人数和组数，结果按组清晰显示
- **连续不重复抽取**：记录已抽成员，剩余人数不足时提示并可重置
- 实时显示已抽人数和剩余人数
- 名单预览（已抽取成员灰色标记）
- 结果字号可调（16-72px）
- 支持 JSON 格式批量导入名单

### 📝 作业布置
- 集中记录作业名称、科目、上交时间
- 关联课表自动计算提醒时间（上课前/上课后）
- 到点发送系统通知
- 按上交时间智能排序（有时间的在前，时间早的优先）
- **桌面作业小组件**：
  - 置顶显示，收缩状态54×54紫色方块
  - 展开状态310×190卡片，显示所有未完成作业
  - 内容区域可滚动，支持显示任意数量作业
  - 支持拖动移动，位置自动保存
  - 四边边界保护，窗口不会移出屏幕

### 🌟 分时段问候语
主页问候语根据时间自动变化，贴合学生作息：
- **早上**（5:00-8:59）：元气满满开始新一天
- **上午**（9:00-11:59）：上课学习进行中
- **中午**（12:00-13:59）：午餐和午休时间
- **下午**（14:00-17:59）：坚持到放学
- **傍晚**（18:00-18:59）：晚饭时间
- **晚自习**（19:00-21:29）：专心完成作业
- **晚上**（21:30-22:59）：准备休息
- **深夜**（23:00-4:59）：劝你早点睡觉

### ⚙️ 完整设置
- 主题颜色自定义（默认 `#8888CC`）
- 默认铃声设置
- 开机自启动
- 名单管理（添加、删除、分组、导入 JSON）
- 课表管理（按星期查看、编辑、导入 JSON）
- 科目老师统一管理
- 内置帮助文档（支持导入 Markdown）

## 📋 数据格式

### 名单 JSON
```json
[
  {"name": "张同学", "group": "一组"},
  {"name": "李同学", "group": "二组"}
]
```

或简化格式：
```json
["张同学", "李同学"]
```

### 课表 JSON
```json
{
  "version": 1,
  "mode": "冬令时",
  "subjectTeachers": {
    "数学": "李老师",
    "语文": "王老师"
  },
  "schedule": [
    {
      "id": "mon-1",
      "weekday": 1,
      "subject": "数学",
      "course": "数学",
      "start": "08:00",
      "duration": 40,
      "breakDuration": 10
    }
  ]
}
```

**字段说明**：
- `weekday`：1-7（周一到周日），省略表示每天重复
- `duration`：课程时长（分钟）
- `breakDuration`：课间时长（分钟）
- `subjectTeachers`：科目老师映射（可选）

**校验规则**：
- 时间格式必须为 `HH:MM`
- 同一天内课程不能时间重叠
- 每个科目只能有一个老师
- 课程 ID 不能重复

## 🛠️ 开发与构建

### 安装依赖
```bash
npm install
```

### 运行测试
```bash
npm test
```

### 启动开发模式
```bash
npm start
```

### 构建 Windows 安装包
```bash
npm run dist
```

构建产物在 `dist/` 目录：
- `Education-Toolkit-Setup-1.0.0.exe`（NSIS 安装程序）
- `Education-Toolkit-1.0.0-x64.msi`（MSI 安装包）
